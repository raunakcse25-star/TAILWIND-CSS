## 📖 Overview

This repository is a structured learning project for **Tailwind CSS**. It demonstrates how to configure Tailwind using **PostCSS**, build responsive web pages, and organize a modern frontend workflow.

Whether you're a beginner or revising concepts, this repository provides practical examples to understand utility-first CSS.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/raunakcse25-star/TAILWIND-CSS.git
cd TAILWIND-CSS
```

## Install Dependencies

```bash
npm install
```

## Run Tailwind Watch

```bash
npm run dev
```

## Build CSS

```bash
npm run build
```
